## Подтверждённые исправления

1. **Размер портретов.** До патча загрузка отказывала WebP свыше 400000 байт, хотя парсер JSON и приватный bucket допускают до 450000. Из-за этого ранее сохранённый файл в допустимом диапазоне 400001–450000 мог не пройти импорт. Предел в процедуре повторной загрузки согласован с форматом и Storage. Новые портреты в интерфейсе по-прежнему оптимизируются до меньшего размера.
2. **Старые заметки Project Moon.** При чтении записей `notes` без `id` использовалось имя по умолчанию `skill-N`. Теперь такие заметки получают `note-N`, не пересекающееся с идентификаторами боевых приёмов. Уже сохранённые непустые ID не переименовываются, тела заметок не изменяются.
3. **Отдельная матрица обратной совместимости.** Создан `tests/compatibility-v02.mjs`, подключён к обязательной команде `npm run test:models`. В нём проверяются версии JSON, старые значения PF2e, смена вида, пользовательские и удалённые поля, старые Project Moon заметки, а также оба формата портретов.

- Создание/восстановление резервных копий продуктивной базы: **0.2.2 остаётся открытой**.
- Проверка RLS двумя непривилегированными аккаунтами: отдельная контрольная точка **0.2.4**.
- Переписывание механики PF2e / CR 3.x, удаление исторических шаблонов и изменение существующих схем Supabase.
