# At your service! — Визуальная версия #1

Основа: приложенный макет главной страницы в духе Long Story Short.

## Что изменено

- Логотип и главный заголовок «At your service!» теперь отображаются в виде векторной надписи, созданной из предоставленного Tilda Script SemiBold. Исходный файл шрифта в репозиторий не требуется и в комплект не входит.
- Компактная шапка с логотипом, переходом в WreckTrack, аккаунтом Google и выходом.
- Верхний блок с подписью и декоративным силуэтом.
- Раздел «Мои персонажи: (N)» с сеткой карточек (3 / 2 / 1 колонки по ширине экрана).
- В карточках: место для будущего портрета, имя, подпись «Раса · Класс» (или сохранённая концепция), цветное обозначение системы, меню действий.
- Кнопка «+» открывает выбор игровой системы, затем ввод имени и создание листа.
- Названия D&D, Pathfinder, Vampire справа от заголовка работают как фильтры; повторное нажатие на активный фильтр показывает все системы.
- Оставлен текущий редактор-черновик листа, Google OAuth, Supabase и RLS. Миграции БД не требуются.

## Важно

Файл `public/wordmark.svg` — контурная надпись из пользовательского шрифта. Весь сайт не требует установки или загрузки самого файла шрифта.

Полей «раса» и «класс» в черновом редакторе пока нет. Подпись карточки — временный ориентир из макета; когда появятся соответствующие поля в листе, карточка сможет использовать `details.race` и `details.class`.

## Развёртывание

Заменить в репозитории `At-your-service` файлы:

- `src/App.tsx`
- `src/styles.css`

Добавить:

- `public/wordmark.svg`
- `docs/VISUAL-V1.md`

GitHub Actions автоматически пересоберёт GitHub Pages после коммита в `main`. Не менять Variables с параметрами Supabase. В рабочем репозитории желательно предварительно убедиться, что другие правки после исходной версии не конфликтуют с этими файлами.
