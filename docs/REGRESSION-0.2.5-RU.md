## Подтверждённое исправление

**PWA / статические ассеты:** `public/sw.js` ранее применял некорректный шаблон расширений `/\\.(...)/`, который не распознавал обычные `.js`, `.css`, `.png` и другие публичные ресурсы. Исправлен на `/\.(...)/` без изменения политики приватности. Добавлен поведенческий тест настоящего сервис-воркера, включая загрузку из кэша без сети и запрет кэша для запросов к сторонним API / OAuth URL.

## Принципы приёмки

1. Для итогового коммита успешны `npm run test:models`, проверка публичного Supabase key, `npm run build`, Chromium PDF/PF2e/библиотека/маршруты.
2. Оба задания GitHub Actions `build` и `deploy` завершены успешно для **одного и того же SHA**.
3. После публикации зафиксировать SHA и URL Actions; не объявлять успешной публикацию при одном зелёном тесте.
4. Если автоматический прогон выявит ещё ошибки, исправить, затем повторить весь прогон.

## Сохранённые ограничения

- **0.2.2:** резервная копия базы данных и приватного Storage ещё не подтверждена восстановлением в отдельном тестовом проекте.
- **0.2.4:** полноценных проверок двух различных пользовательских JWT (доступ к чужим записям и файлам) не проводили.
- Ни игровых правил Pathfinder/Project Moon, ни формата JSON v1, ни существующих таблиц/миграций Supabase этот этап не изменяет.
