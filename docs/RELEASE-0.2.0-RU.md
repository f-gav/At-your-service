# At your service! — версия 0.2.0

**Дата фиксации:** 18 октября 2026 года  
**Тип:** технический выпуск «Закрепление платформы»  
**Статус:** опубликованная кодовая версия; два обязательных эксплуатационных испытания остаются открытыми. **Не считать выпуск полностью сертифицированным по восстановлению данных или межаккаунтной изоляции.**

## Основное

At your service! поддерживает создание персонажей двух систем — Pathfinder 2e и Project Moon TTRPG. Для Pathfinder доступны классический и альтернативный HTML-листы, использующие совместимые данные. D&D и Vampire: The Masquerade остаются недоступными для создания нового персонажа.

### Стабилизация

- Обновлены README, инструкции установки и эксплуатации, единая дорожная карта.
- Проведён статический и live-аудит RLS персонажей, административных шаблонов, функций публикации и приватного bucket портретов без изменения записей пользователей.
- Добавлен `supabase/security-audit.sql` для безопасного повторного чтения структуры прав.
- Подготовлены инструкция бэкапа/восстановления `docs/BACKUP-RESTORE-RU.md` и read-only-инвентаризация `supabase/backup-integrity.sql`.
- Проверена совместимость JSON v1, старых данных Pathfinder/Project Moon, скрытых полей и двух форматов WebP-портретов.
- Исправлен импорт ранее допустимых портретов 400–450 КБ, согласовав его с предельным размером Storage.
- Исправлены ID заметок Project Moon при чтении старых записей без идентификаторов.
- При смене аккаунта административные элементы скрываются немедленно до получения новых прав с сервера.
- Исправлен шаблон расширений публичных файлов в PWA-сервис-воркере: JS/CSS/изображения снова доступны для кэширования, без кэширования приватных ответов.
- Добавлен исполняемый регрессионный тест PWA-кэша.
- Стабилизированы PDF, маршруты, редакторы и HTML Pathfinder; последние патчи таблицы заклинаний устранили нежелательное изменение порядка при перетаскивании заклинания на себя.

### Библиотека

- Библиотека Pathfinder 2e включает чары и заклинания первого/второго ранга. Наличие русских карточек не означает, что все переводы и механики прошли независимый редакторский аудит.
- D&D-каталог пока пуст.
- Содержимое библиотеки проверяется тестами целостности и браузерной навигации.

## Проверки выпуска

Пайплайн `.github/workflows/deploy.yml` включает:
1. `npm run test:models` — модели, JSON, портреты, шаблоны, сохранение, PWA, Pathfinder, Project Moon, библиотека.
2. Проверку публичной конфигурации Supabase.
3. `npm run build` — TypeScript и Vite.
4. `npm run test:pdf-browser` — экспорт PDF в Chromium.
5. `npm run test:pf-alternative-browser` — компьютерные и мобильные размеры HTML Pathfinder.
6. `npm run test:spell-library-browser` и `node tests/routes-static-browser.mjs` — библиотека и маршруты.
7. `deploy` на GitHub Pages после успешного `build`.

**Принятие 0.2.6:** окончательные SHA, URL CI и подтверждение `build + deploy` для конкретного SHA указываются в отчёте о выпуске после завершения пайплайна. Не подменять успешное развертывание фактом существования коммита.

## Открытые эксплуатационные требования

**0.2.2 — восстановление бэкапа:** нужен полный набор БД, истории шаблонов и приватных файлов Storage, затем тестовое восстановление в отдельной среде. Аудит связности данных и инструкция существуют, но восстановление не проверено.

**0.2.4 — межаккаунтные E2E:** нужен отдельный тест непривилегированными аккаунтами A/B по API с проверкой доступа к чужим персонажам, путям Storage и публикации шаблонов. Проверка определений RLS/RPC в действующей базе проведена, но не эквивалентна такому тесту.

**Дополнительные ограничения:** не проведена сплошная проверка игровых механик Project Moon CR 3.x и всех заклинаний Pathfinder, ручная приёмка на физических Android/iOS и проверка конкурентного редактирования одного листа двумя устройствами.

## Совместимость и безопасность

- Формат экспортируемого персонажа **JSON v1 не меняется**.
- Действующие схемы Supabase, игровые формулы и права пользователей в этом выпуске не изменялись.
- Полноценная автономная синхронизация не заявлена. PWA кэширует только публичную оболочку; данные персонажей сохраняются в Supabase при наличии сети, временные несохранённые изменения — в локальном черновике.
- Бэкапы, персональные данные и OAuth-секреты не включаются в git, публичный CI или релизные артефакты.
- `package.json` фиксирует техническую версию `0.2.0`. Git tag/GitHub Release при необходимости создаются отдельно после приёмки открытых эксплуатационных требований, чтобы не обозначать релиз окончательно закрытым.
