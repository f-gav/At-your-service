# Pathfinder 2e — локализация подтверждённых названий, 13 октября 2026

## Итоги

- Состояние до работы: **125 RU / 134 EN**.
- Добавлено **77 русских названий**, сверенных по английским ключам в модуле [PF2e: перевод по терминологии PF2.ru](https://github.com/DoctorWater/pf2ru-translation). Модуль официально описан на [PF2.ru / Foundry](https://pf2.ru/foundry) как использующий тексты с PF2.ru.
- Дополнительно **Invoke True Name → «Призыв истинного имени»** найден в [старом справочнике](https://pf2e-ru-translation.readthedocs.io/ru/latest/spells/all-spells.html).
- Итого: **203 RU / 56 EN** из 259 карточек. Английские оригиналы и Legacy/Remaster сохранены.
- Русские описания, добавленные на этом этапе, — **краткие самостоятельно сформулированные черновики**, а не опубликованный перевод полного текста; детализацию позже можно расширять по оригинальным механикам Foundry. Чужой литературный перевод не импортирован.
- Сопоставление 77 названий сделано по модулю сайта, **не** прямым ручным открытием всех 77 страниц. Проверить расхождения при дальнейшей редактуре.
