# Этап 3 — пакет №3 из 5: общий редактор

- Универсальный `RichField`, кодек, спойлеры, разделители, формулы кубиков, ресурсные виджеты, диалог ресурсов и координатные помощники перенесены в `src/features/rich-editor/`.
- Общая плавающая навигация и геометрия перемещены туда же.
- Pathfinder и Project Moon импортируют редактор и навигацию напрямую из общего модуля; зависимость Project Moon от `pathfinder/RichField` и `pathfinder/FloatingPageNavigation` устранена.
- Старые пути TypeScript оставлены исключительно совместимыми реэкспортами, чтобы исторические импорты не ломались.
- Кодек разметки, CSS-классы, сериализация, игровые формулы и PDF не переписывались.

- [ ] Все тесты моделей, редактора, JSON и форматирования.
- [ ] Chromium: мобильные размеры и геометрия страниц.
