# Броски кубиков — этап 1 и дальнейшая интеграция комнат

## Этап 1: локальные формулы в Pathfinder / Project Moon

Один и тот же `RichField` теперь позволяет выделить обычный текст формулы
и нажать кнопку с кубиком или `Ctrl+D` (`Cmd+D` на Mac). Поддержка встроена
во все обычные богатые текстовые поля обоих листов, включая вложенные
описания, заметки, условия и способности.

После подтверждения корректности формула сохраняется как безопасный
`data-pf-dice`-элемент внутри имеющегося `ays:rich:v1:`. Никакой миграции
полей персонажа или версии JSON не требуется. При клике формула выполняется,
на экране справа снизу появляется отдельная локальная история и расшифровка
брошенных граней. Контекстное меню (ПКМ) возвращает формулу в обычный текст.
В панели также можно бросить произвольную введённую формулу.

Поддерживаются:
- `NdS`, `d20`, `1к8`, арифметика `+ - * /`, круглые скобки.
- `kh`, `kl`, `dh`, `dl` для выбора/отбрасывания лучших/худших граней.
- `floor`, `ceil`, `round`, `abs`, `min`, `max`.
- Именование `1d20+5 (Атака)` или `2d8 # Огонь`.
- Переменные PF2e `[STR]`, `[DEX]`, `[CON]`, `[INT]`,
  `[WIS]`, `[CHA]`, `[LVL]`; Project Moon `[RANK]`,
  `[FORTITUDE]`, `[PRUDENCE]`, `[DETERMINATION]`, `[CHARM]`,
  `[DISCERNMENT]`, `[TEMPERANCE]`. Из неизвестных/пустых характеристик
  значение не придумывается, показывается ошибка.
- Лимиты 1000 символов / 1000 костей / 32 вложения, проверенный
  парсер без `eval` и случайные грани через `crypto.getRandomValues`.

**Не входит в этап 1:** полный синтаксис Roll20/LSS (взрывы, перебросы,
групповые броски, `if`, вычисляемое количество костей), автоматический
бросок по клику на значения навыков и оружия, накопление истории в облаке,
синхронизация между устройствами, отправка в Telegram / Discord / Vortex.
Для таких формул показывается ошибка, а не молчаливый неверный бросок.

## Этап 2: расширение движка

- Добавить недостающие конструкции нотации LSS с расширенными
  испытаниями математических выражений и фиксированного генератора.
- Отдельные привязки к навыкам, спасброскам, атакам/урону PF2e и
  проверкам Project Moon без изменения игровых правил.
- Уточнить поведение критов, преимущества/помехи для каждой системы;
  нельзя автоматически переносить правила D&D 5e на PF2e / Project Moon.
- UX мобильного редактирования формул и отключения бросков.

## Этап 3: собственные комнаты для At your service!

Сохраняем совместимый объект события `DiceResult`: `formula`,
`label`, `total`, `dice` с отдельными гранями `faces`, `kept`.
Когда будут введены кампании/комнаты, дополнить событие неизменяемым
ID, ID персонажа и автора, временем сервера и признаками контекста броска.
Раздельно решить вопросы прав, видимости бросков, RLS, rate limits и
идемпотентности; отправка в комнату включается явно.

**Vortex принадлежит Long Story Short.** Нет предположения о публичном
API стороннего Vortex или разрешённой записи в его комнаты. Для совместной
игры лучше внедрить собственный журнал комнат At your service! с отдельными
опциональными интеграциями Telegram/Discord (через серверные функции,
не раскрывая токены клиенту).
