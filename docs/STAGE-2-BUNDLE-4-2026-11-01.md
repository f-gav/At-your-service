## Подтверждённые дефекты

- [x] **Pathfinder JSON терял скрытые таблицы заклинаний.** Когда лист использовал библиотечный режим, экспорт отбрасывал прежние `cantrip_names`, `spellbook_left_names` и другие текстовые таблицы. При обратном импорте и переключении в текстовый режим они пропадали. Теперь исторические значения транспортируются в `sheet.spells.legacyText` (не дублируют активные библиотечные поля), восстанавливаются при импорте и не создают старых заклинаний в библиотечной раскладке. Обратная совместимость с ранее созданными JSON v1/v2 сохранена.
- [x] **Экспортируемый JSON можно было не суметь импортировать:** `parseCharacterJson` отвергал `details` длиннее 50 КБ, хотя файл в целом допускался до 2 МБ. Листы Project Moon с четырьмя текстовыми колонками, форматированием, оружием, бронёй, аугментами и заметками могут превышать 50 КБ без ошибок. Повышена граница данных листа до 1,5 МБ (максимальный размер загружаемого JSON остаётся 2 МБ); данные не обрезаются.
- [x] Добавлен большой тест реального JSON-кодека Pathfinder, включая заметки, скрытые страницы, раскладку и прежние заклинания, а также Project Moon с четырьмя колонками, богатым текстом, бронёй, аугментами, страницами, оружием, флагами и незнакомыми полями будущих версий.
- [x] Расширен прежний тест совместимости JSON, чтобы не допустить возвращения потери исторических текстовых таблиц.
- [x] Добавлен браузерный тест на настоящих компонентах для 390/1360px: редактирование Project Moon → подтверждение сохранения → перезагрузка → броня/аугменты/четыре колонки → скрыть страницу → перезагрузка → показать страницу и подтвердить сохранённое содержимое; Pathfinder — переход из альтернативного бланка в классический и повторное открытие.
- [x] Подготовлен тестовый `?reopen=1` режим **только в `tests/pdf-harness.tsx`**, сохраняющий синтетический подтверждённый снимок в `sessionStorage`. Никакой пользовательский или production-код не перенаправляется на это хранилище.

## Мобильный макет — отдельный пакет №5

Аудит обнаружил правила `ProjectMoonSheet.css` `@media(max-width:660px)`, которые сворачивают `.moon-two-columns`, `.moon-resistance-layout`, `.moon-about-duo` и части dossier в один столбец. Изменение одного селектора без согласованной сетки может испортить бланк и PDF. Поэтому полноценное сохранение **страничной структуры** на телефоне (адаптивное масштабирование области страницы, чёткая сетка, отсутствие вертикального превращения структурных секций в список, доступное редактирование, защита PDF) выполняется одним целостным пакетом №5. Здесь мы его не маскируем отдельными CSS-правками.

## Безопасность и выпуск

- Production Supabase, RLS, RPC, Auth, Storage, пользовательские данные и игровые правила **не изменяются**.
- Изменяется только транспорт JSON; существующие сохранения не мигрируются.
- Тесты модели и браузера используют синтетические данные, реальные два непривилегированных JWT из этапа 1 пока не подтверждены.
- Обязательные проверки: npm test:models, TypeScript/Vite, PF2e/Project Moon/PDF, тёмная тема, мобильные формы, новые JSON и browser roundtrip, Windows smoke и изолированный PostgreSQL.
- Выпуск: один PR → green CI → squash main → GitHub Pages deploy → проверенная ревизия.
