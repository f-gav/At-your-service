# Альтернативный PF2e — HTML-лист персонажа (первый выпуск)

## Назначение

Вторая, переключаемая форма **того же Pathfinder 2e-персонажа**. Текущий классический бланк на изображениях русского PDF не заменяется и остаётся доступен в любой момент.

Визуальные ориентиры: `RM_CharacterSheetRus.pdf` (4 страницы), `Pathfinder_2e_RU_editable_V1.pdf` (4 страницы), HTML-подход Pr. Moon и интерфейс LSS. Все игровые значения должны использовать старые постоянные идентификаторы из `fields.json`, а не новые параллельные поля.

## Переключение без конвертации

- `characters.system` остаётся `pf2e`.
- `characters.details.pathfinderSheet` сохраняется по прежней схеме, включая автоматически вычисляемые поля, навыки, заметки, подготовленные заклинания и инвентарь.
- Только ключ `pathfinderSheet.pf2e_layout` отличается: `classic` либо `alternative`. Если ключа нет, показывается классический лист.
- При переключении на странице переключатель сразу меняет представление; автосохранение записывает этот ключ вместе с остальными значениями.
- При создании PF-персонажа и импорте PF-JSON пользователь выбирает представление; в меню персонажа можно переключить его и позднее.
- Экспорт JSON остаётся форматом `at-your-service-character` версии 1: поля не переименовываются, импорт не конвертирует механику.

## Страницы HTML-версии

1. Персонаж, характеристики, защиты и ПЗ, навыки, оружие, КС класса.
2. Черты и классовые способности, повышение уровня, инвентарь, валюта.
3. Внешность, связи и кампания, стандартные/ответные действия, портрет.
4. Магические традиции, ячейки, чары, заклинания, фокусные/врождённые заклинания, ритуалы.
5. Опциональная страница заметок повторно использует исходные ключи заметок.

Неописанные новые поля опубликованной админ-схемы показываются автоматически в разделе «Дополнительные поля», не пропадая при обновлении шаблона.

HTML-версия использует существующие `RichField`, формулы Pathfinder, гримуар, диалог заклинаний, портрет, сохранение, PDF-экспорт (рендер HTML-страниц) и настройки порядка страниц.

## Ограничения первого выпуска

- Сетка HTML сохраняет **структуру** русского бланка, но не копирует пиксель в пиксель координаты PDF. Дополнительная визуальная подгонка по игровым сценариям возможна отдельными патчами.
- HTML-страницы подстраиваются под содержимое; при экспорте в PDF длинные страницы могут занимать более одного листа А4, чтобы не обрезать записи.
- Взаимодействие с особым оружием, трёхдействием и некоторыми администраторскими пользовательскими полями следует визуально проверить на реальных персонажах.
- Отдельная регистрация новых таблиц Supabase или изменение JSON не требуются.

## Регрессионная проверка

`tests/pathfinder-alternative.mjs` проверяет перенос тех же значений между двумя видами, наличие всех HTML-страниц и переключение при импорте. Общий workflow выполняет TypeScript, тесты моделей и браузерные тесты существующей библиотеки и PDF.
