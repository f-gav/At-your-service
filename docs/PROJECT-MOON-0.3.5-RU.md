# At your service! — Project Moon 0.3.5: административный редактор

**Объём:** безопасность работы с черновиками, корректность истории оформления и сохранность ранее созданных листов. **Supabase-публикация рабочего шаблона не выполнялась.** Игровые правила, миграции и JSON v1 не изменялись.

## Аудит

- Редактор Pr. Moon сохраняет черновики в `sheet_template_drafts`, а публикацию выполняет через `publish_sheet_template` после успешного сохранения черновика.
- История опубликованных шаблонов берётся из `sheet_template_history`. Загрузка исторической версии восстанавливает её в редактор, но **не публикует**.
- Проверен прежний формат шаблонов: `parseMoonLayout` дополняет отсутствующие ранее элементы типографики и координаты маски значениями по умолчанию. Отдельные стили блоков проходят сериализацию.
- Настройки ширины и смещения рамки портрета независимы от ширины, высоты и смещения маски. Данные портретов персонажей не меняются.
- Общий предпросмотр Project Moon использует `layoutOverride`, тогда как обычный лист использует комплектную опубликованную разметку; редактор не изменяет персональные листы.

## Подтверждённые исправления

1. После удачной RPC-публикации редактор обновляет не только номер, но и **локальную копию опубликованного оформления**. Сравнение с опубликованной версией больше не использует устаревшее значение.
2. Загрузка старой версии в редактор записывает состояние в Undo перед заменой. Предыдущее оформление можно восстановить через отмену.
3. **Отдельная задача Pathfinder 2e:** имя разделителя в списке заклинаний теперь отрисовывается жирным (`font-weight: 700`) в классическом и HTML-листе, включая PDF-стили. Текст разделителя остаётся обычной строкой, старые записи менять не требуется.

## Регрессионные проверки

- `tests/project-moon-admin.mjs`: прежние и новые шаблоны, рамка и маска, типографика, черновики, права публикации по существующей RPC, корректный локальный статус опубликованной версии, отмена загрузки истории.
- `tests/pathfinder-spell-layout.mjs`: порядок и положение заклинаний, разделители, сохранение/восстановление JSON и проверка жирности текста в CSS.
- Стандартный CI: модели, TS/Vite, PDF в Chromium, альтернативный Pathfinder и библиотека.

## Отложенные ограничения

**Не выполнены:** интерактивный E2E двух аккаунтов для административных прав, настоящее восстановление резервной копии 0.2.2, ручная проверка редактора на реальных мобильных устройствах и реальная публикация тестового шаблона в изолированной Supabase. Эти вопросы не объявляются закрытыми по результатам статических тестов.
