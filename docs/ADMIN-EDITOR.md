# Редактор листа Pathfinder 2e — административный режим

Вход: после авторизации администратора через Google доступна кнопка «Редактор листов». Доступ проверяют таблица sheet_admins и RLS-политики Supabase (не браузер и не Google user_metadata).

Возможности: выбор страницы 1–4; перемещение поля мышью и изменение размеров; координаты X/Y/W/H в PDF-пунктах; выбор шрифта, размера, начертания, цвета, выравнивания и отступов; создание/удаление поля, типы text/long/number/counter/toggle; масштаб, привязка к сетке, предпросмотр, отмена/повтор. Кнопка черновика сохраняет отдельную схему только для администратора. Публикация создаёт версию в истории и изменяет лист пользователей.

Файлы:
- src/features/pathfinder/editor-schema.ts — модель, исходные поля, проверка схемы.
- src/features/pathfinder/TemplateAdmin.tsx и TemplateAdmin.css — редактор.
- src/features/pathfinder/PathfinderSheet.tsx — отображение опубликованной схемы.
- supabase/migrations/20261010_template_admin_editor.sql — база, RLS и атомарная RPC публикации.

Удалённые из шаблона поля должны сохранять значения существующих персонажей. При недоступной опубликованной схеме используется исходный шаблон.

Следующие улучшения: горячие клавиши, групповое выравнивание, дополнительные типы блоков, серверная проверка значений каждой схемы, тесты браузера на телефонах и E2E публикации.

## Выпадающее меню

Выбери поле → «Тип» → «Выпадающее меню». В появившемся редакторе впиши варианты по одному в строку (1–60 уникальных вариантов, до 100 символов каждый). Для поля `size` по умолчанию предлагаются шесть размеров PF2e. Варианты хранятся в `sheet_templates.fields[].options`, выбор пользователя — строкой в `characters.details.pathfinderSheet[id]`. Изменение списка не удаляет прежнее сохранённое значение.

## Постоянная нижняя линия (версия 1.1)

Для текстового поля, числа, счётчика, многострочного текста или выпадающего списка появилась опция **«Показывать нижнюю линию, даже без текста»**. Линия видна сразу в предпросмотре администратора и в опубликованном листе **даже при пустом значении**. Галочки не затрагиваются. Это часть схемы шаблона (`underline?: boolean`), а не данных персонажа. Чтобы настройка появилась у всех, сохрани черновик и нажми «Опубликовать».

## Пробные значения и публикация

Пробные значения в административном редакторе используются **только в предпросмотре**. При публикации сохраняются координаты, размеры, шрифты, оформление и типы полей; данные уже созданных персонажей не заменяются временными примерами. Чтобы изменить уровень, опыт или другие значения конкретного героя, необходимо открыть сам лист персонажа. В интерфейсе это теперь явно отмечено, и добавлена кнопка очистки тестового значения.

## Нажимные поля произвольной формы (2026-10-10)

Для существующей **«Отметки»** или нового поля этого типа появились:
- Форма: квадрат, прямоугольник, круг, ромб, шестиугольник.
- Вид нажатия: галочка или заливка фигуры.
- Отступы заливки по осям X/Y (0–40%), чтобы точно вписывать закраску в нарисованные рамки.
- Настраиваемые координаты X/Y и размеры W/H в пунктах PDF; перемещение и изменение размеров прямо поверх листа. Быстрые размеры 7×7, 10×10, 15×15, 20×20 с сохранением центра.
- «Пробное нажатие» позволяет увидеть выбранную форму непосредственно в админ-редакторе. Пока оно выключено, редактор показывает полупрозрачный ориентир формы, который отсутствует в опубликованном листе.

Пункты героизма без настроек формы сохраняют прежнее поведение: шестиугольник с заливкой. Другие отметки по умолчанию показывают галочку. Изменение формы, положения и размера не меняет идентификатор поля или boolean-значение персонажа. После расстановки нажми «Сохранить черновик», затем «Опубликовать».

У изображения портрета PF2e больше нет обводки при наведении. Клавиатурный `focus-visible` сохранён для доступности.
