# Этап 3 — пакет №4 из 5: Rooms и Library

Базовая ревизия: `2371ef1`. PR относится только к архитектурному рефакторингу.

## Rooms
- Запросы к Supabase `game_rooms`, `game_room_members`, `game_room_rolls` и RPC `join_game_room` вынесены в `room-repository.ts`.
- RLS остаётся серверным, не создаются новые политики, миграции или обходы серверного доступа.
- Сохранены ограничения выбора персонажей, клиентский throttle, Realtime и fallback-опрос.
- UI, тексты, права мастера и правила бросков остаются прежними.

## Library
- `library-query.ts` содержит загрузку каталога, выбор редакции, фильтрацию, специальное правило D&D-ритуалов, фильтр источников, постраничную выдачу и признак активного фильтра.
- Отображение карточек и модальные окна остались в `SpellLibrary.tsx`; полная декомпозиция UI — оставшийся технический долг.
- Никакие игровые данные или источники магии не изменены.
