# Этап 2 — пакет №2: адаптивность, ошибки и модальные окна

Дата: 1 ноября 2026. Один объединённый PR, без новых функций в БД и без изменений игровых правил.

## Подтверждённые проблемы и исправления

- [x] Ошибка `setError(...)` на вкладке библиотеки/комнат была невидима: `global-error` рендерился **только внутри Home**. Глобальные ошибки теперь показываются в общем контейнере под шапкой на любой вкладке, в том числе в редакторах. При открытых диалогах ошибка отображается внутри диалога, без дублирования.
- [x] Сообщение «Ссылка скопирована» было ошибочно оформлено как `role="alert"`; теперь успешное копирование имеет отдельный `role="status"`.
- [x] В `RoomsHub.tsx` диалог дважды рендерил идентичный `ays-room-dialog-error`. Убрана вторая копия и внешний повторный алерт на фоне модального окна.
- [x] Запрос обновления комнат не имел состояния ожидания: теперь кнопка отключена пока идёт запрос, а список показывает загрузку. Создание/подключение отображают «Создаём…» и «Подключаем…».
- [x] Длинные имена в карточках персонажей обрезались `white-space:nowrap` и фиксированной высотой 78px; разрешена естественная высота карточки и переносы.
- [x] Названия заклинаний в каталоге искусственно обрезались после двух строк `-webkit-line-clamp:2`; ограничение снято. Длинные параметры на узком экране теперь переносятся.
- [x] Окна создания, импорта и дублирования, а также комнаты, могли оказаться **под закреплённой шапкой** (`z-index:20/1100` против `10000`). Область модального окна теперь выше шапки и помещается по высоте мобильного viewport.
- [x] Для модальных окон добавлено запирание фокуса по Tab, закрытие по Escape (если операция не выполняется), блокировка прокрутки фона и возвращение фокуса на вызывавшую кнопку.
- [x] Текст ошибок, заголовков и подписей не выпадает за края маленького экрана; дополнительные ограничения размеров форм на 320–390px.
- [x] В CI добавлен реальный Chromium browser smoke без Supabase-ключей: отсутствие пропавших ошибок на Library/Rooms, длинные названия, проверка размеров модальных окон на 320x568, 390x667, 1360x800, приоритет модального окна над шапкой, Tab/Shift+Tab/Escape, восстановление фокуса и scroll lock.

## Область изменений

`src/App.tsx`, `src/styles.css`, `src/features/rooms/RoomsHub.tsx`, `RoomsHub.css`, `src/features/spell-library/SpellLibrary.css`, `src/lib/use-modal-accessibility.ts`, browser fixture и тесты, GitHub workflow.

Не изменяем SQL, Supabase Auth, RLS, RPC, данные пользователя, JSON/PDF модели и правила игровых систем. Отложенная модель комнат: **один персонаж может находиться только в одной комнате** — оставить для отдельного согласованного изменения Rooms V2.
