# ТЗ: редизайн библиотеки заклинаний — широкая сетка LSS

Статус: дизайнерский патч, без импорта новых заклинаний. Референс: предоставленный пользователем скриншот гримуара Long Story Short. Не копировать его бренд, цвета или содержание.

## Цель
Библиотека Pathfinder 2e и D&D 5e рассчитана на ~2000 записей и должна позволять быстро сравнивать параметры заклинаний, не открывая каждую карточку. Пользователь должен видеть 3–4 заклинания в одной строке на большом мониторе. Сохранить привычную верхнюю навигацию «Персонажи / Библиотека» At your service!, единый каталог и всплывающее описание.

## Макет
- Только страница библиотеки: максимальная ширина **1600 px** с боковыми полями 24–32 px; ни главную страницу персонажей, ни редактор листов не расширять.
- Убрать постоянную боковую колонку категорий, освободив ширину под сетку. Категории перенести в горизонтальные компактные кнопки.
- Широкий экран ≥1500 px: **4 колонки**; 1050–1499 px: **3**; 680–1049 px: **2**; узкий экран: **1**. Плитки одинаковых минимальных высот с гибким содержимым.
- Заголовок, система/редакция и счётчик результатов не заслоняют каталог.
- Клики по карточкам открывают существующее модальное окно; остаются Escape, щелчок снаружи, возвращение фокуса и сохранение позиции списка.

## Карточка каталога
- Компактная плитка в светлом приглушённом зелёно-сером тоне, текст читаемый на светлом фоне.
- Название — основная строка (16–17 px, до двух строк), под ним тип («Чары» / «Заклинание N-го круга»). Английское название не дублировать в списке; оно остаётся внутри всплывающей карточки.
- Нижняя строка метаданных: **сотворение**, **дистанция**, **защита** (если параметры отсутствуют — длинное тире); небольшие иконки и пояснения через title/aria-label.
- Маркер книги компактный (две–три буквы), полное название книги в подсказке. Не придумывать числовые показатели или урон из описания.
- Визуальные состояния hover/focus/active, без отдельного вложенного клика.
- Сортировка остаётся по кругу и названию, загрузка по 50 записей.

## Фильтрация
- Сверху — поиск и кнопка «Фильтры» с видимым состоянием раскрытия. Рядом компактный «Сбросить».
- На виду **быстрые кнопки уровня/круга**: Все, 0, 1…10 для PF2e; Все, 0…9 для D&D. 0 включает чары/заговоры; не маркировать чары PF2e как «магия нулевого круга» внутри подробной карточки.
- На виду **типы**: Все, Чары, Заклинания, Фокусные, Ритуалы, Особая магия; для D&D не показывать фокусные и особую магию. «Мои заклинания» оставить как ещё не реализованный раздел с пустым состоянием.
- Расширенная панель по запросу: редакция, традиция (PF) / школа (D&D), класс, редкость, язык, источник. Предусмотреть свободное изменение параметров и очистку фильтров.
- Сохранить корректную особенность D&D: ритуал — свойство заклинания, а не отдельный вид.
- При изменении быстрого фильтра сбрасывать конфликтующий фильтр (например, круг 1 после выбора чар), чтобы интерфейс не заводил в пустое пересечение неожиданно.
- Переключение системы очищает поисковый запрос и зависимые фильтры, каталог другой системы не перемешивается.

## Мобильная версия
- Поиск остаётся на всю ширину, кнопка расширенных фильтров рядом или ниже; чипы кругов/типов имеют горизонтальную прокрутку.
- Никакого горизонтального скролла всего документа, перекрытия текста или обрезания кнопок. Области нажатия минимум ~40 px.
- 1 колонка до 679 px, 2 колонки на планшете.

## Границы патча
Не менять JSON-схему, данные уже импортированных 24 чар, тексты заклинаний, поведение PDF и карточек персонажей, Supabase, экспорт/импорт.

## Критерии приёмки
1. Браузер в ширинах 390 / 820 / 1280 / 1700 px показывает 1 / 2 / 3 / 4 карточки в строке соответственно.
2. Выбор круга, типа, поисковый запрос и сброс действительно меняют набор записей; фильтры скрываются/открываются.
3. Щелчок по карточке открывает модальное окно, после закрытия список и позиция прокрутки сохранены.
4. На D&D по-прежнему пустой каталог, но быстрые фильтры готовы к импорту.
5. Сборка TypeScript, старые тесты PDF, браузерные тесты библиотеки и успешный Deploy GitHub Pages.
