# Библиотека заклинаний — платформа v1

**Текущий патч содержит только интерфейс и модель данных.** В репозитории специально
нет заполненных заклинаний, включая примеры: обе публичные базы содержат ноль записей.

## Структура

- `src/features/spell-library/SpellLibrary.tsx` — каталог, поиск, категории, фильтры,
  карточка описания, переключение правил Pathfinder / D&D.
- `catalog.ts` — версии заклинаний, перевод, источник, поиск, фильтрация и проверка импорта.
- `SpellLibrary.css` — изолированные адаптивные стили, не затрагивающие листы персонажей.
- `public/spell-library/pf2e.json` — пока пустой каталог Pathfinder 2e.
- `public/spell-library/dnd5e.json` — пока пустой каталог D&D 5e.
- `tests/spell-library.mjs` — проверки модели и того, что каталоги пусты.
- `tests/spell-library-browser.mjs` — проверки вкладок/поиска/фильтров на компьютере и телефоне.

Ссылка на вкладку: `/At-your-service/#library`. Персонажи, их JSON и
автосохранение остаются без изменений.

## Единица каталога

1. **SpellIdentity** — стабильный ID, игровая система, вид магии, базовый круг/уровень,
   традиции PF2e или классовые списки D&D, черты, редкость, источник.
2. **SpellRulesVersion** — механика конкретной редакции (`pf2e-remaster`,
   `pf2e-legacy`, `dnd-2024`, `dnd-2014`).
3. **SpellTranslation** — языковой текст и статус перевода; связь с версией
   позволяет менять перевод или редакцию без клонирования магии.
4. **SpellSource** — книга, издатель, год, ссылка и сведения о лицензии.
5. **SpellReference** — будущая ссылка на заклинание в карточке персонажа;
   подготовка, собственные заметки и источник получения хранятся у персонажа.

Отличия механик: в PF2e ритуал — отдельная категория; в D&D ритуальное
сотворение является свойством обычного заклинания (`rules.ritual`).
Школы D&D не используются вместо четырёх традиций Pathfinder.
Фокусная магия не смешивается с обычными ячейками.

## Как добавлять материалы позднее

Импортированная запись должна находиться в `spells`, версия правил — в
`versions`, перевод — в `translations`, источник — в `sources`. Запись
без связанной версии для выбранной редакции не показывается. Русский перевод
предпочитается, при его отсутствии показывается английский.

Проверка `parseSpellCatalog` обнаруживает несовпадение игровой системы,
неподдерживаемую схему, повторные ID и оборванные связи. Любые новые импорты
проходят эти проверки до публикации.

Перед переносом описаний из чужих переводов, PDF и сайтов отдельно выясняем
условия использования. Этот патч **не публикует чужой текст заклинаний**.
