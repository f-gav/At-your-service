# At your service

Минималистичные цифровые листы персонажей для настольных ролевых игр — Dungeons & Dragons 5e, Pathfinder 2e Remaster и Vampire: The Masquerade V5.

Проект на раннем этапе (alpha): система аккаунтов и библиотека персонажей, базовые свободно заполняемые черновики. Оригинальные игровые листы будут добавлены после утверждения макетов.

## Что входит в версию 0.1

- Светлое адаптивное главное меню и три раздела игровых систем.
- Регистрация/авторизация через Google OAuth с Supabase Auth.
- Личная библиотека персонажей с фильтрами по системе.
- Создание, редактирование и удаление собственных персонажей.
- Сохранение имени, концепции, кампании и заметок в Supabase.
- Row Level Security (RLS): доступ только к собственным данным.
- Автоматическая сборка и публикация через GitHub Actions и GitHub Pages.

**Полная инструкция по развёртыванию: [docs/SETUP-RU.md](docs/SETUP-RU.md).**

**План разработки: [docs/ROADMAP.md](docs/ROADMAP.md)** — следующий крупный этап: визуальный редактор листов.

## Разработка

```bash
npm install
cp .env.example .env.local
npm run dev
```

Параметры в `.env.local`: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`.

Проверка сборки: `npm run build`. Публикация: `.github/workflows/deploy.yml`.

## Структура

- `src/App.tsx` — главный экран, библиотека, черновик листа, операции с персонажами.
- `src/lib/models.ts` — системы и модель данных персонажа.
- `src/lib/supabase.ts` — подключение Supabase и вход через Google.
- `src/styles.css` — минималистичный интерфейс и мобильная адаптация.
- `supabase/schema.sql` — таблица, индексы и политика доступа.
- `docs/SETUP-RU.md` — инструкция владельцу.

## Безопасность

Frontend не содержит Google Client Secret, паролей или Supabase secret/service_role keys. Публичный Supabase publishable key допустим в браузере **только при корректно включённых RLS-политиках**. Листы других пользователей не запрашиваются и скрыты средствами RLS.
