# At your service!

Минималистичная платформа интерактивных листов персонажей для настольных ролевых игр.

**Состояние на 16 октября 2026 года:** в приложении доступны игровые листы **Pathfinder 2e** (классический и альтернативный HTML) и **Project Moon TTRPG**. Dungeons & Dragons 5e и Vampire: The Masquerade V5 присутствуют в списке систем, но создание новых игровых листов для них пока не включено.

## Рабочие возможности

- Google OAuth через Supabase Auth, личная библиотека персонажей, фильтры и изменение порядка карточек.
- Приватные персонажи с PostgreSQL RLS и приватные портреты в Supabase Storage.
- Pathfinder 2e: два переключаемых представления с общими значениями, характеристики, навыки, боевые показатели, заклинания, инвентарь и необязательные страницы заметок.
- Project Moon: четыре HTML-страницы с ресурсами HP/ST/SP/Light, оружием, боевыми приёмами, портретом и заметками. Полная механическая сверка с CR 3.x ещё требуется.
- Административные редакторы шаблонов, черновики, опубликованные версии и история.
- Автосохранение, аварийные локальные черновики, дублирование, экспорт PDF и перенос персонажей через JSON v1.
- Библиотека заклинаний: Pathfinder 2e (чары и 1–2 ранг, локализация), отдельный пока пустой каталог D&D.
- PWA с установкой на устройство и ограниченным офлайн-доступом к публичной оболочке; полноценная офлайн-синхронизация отсутствует.
- Проверки моделей, TypeScript/Vite, PDF и Chromium в GitHub Actions с публикацией на GitHub Pages.

**Сайт:** https://f-gav.github.io/At-your-service/

## Разработка

```bash
npm install
cp .env.example .env.local
npm run dev
```

В `.env.local` укажите только `VITE_SUPABASE_URL` и **публичный** `VITE_SUPABASE_PUBLISHABLE_KEY`. Никогда не размещайте `service_role`, секреты Supabase, пароли и Google Client Secret в коде, JSON персонажей или GitHub.

```bash
npm run test:models
npm run build
npm run test:pdf-browser
npm run test:pf-alternative-browser
npm run test:spell-library-browser
```

Браузерные тесты требуют установленного Chromium от Playwright. Сборка и развертывание: `.github/workflows/deploy.yml`.

## Безопасность и сохранность данных

RLS-политики находятся в `supabase/schema.sql` и `supabase/migrations/`. **Наличие миграций в GitHub не подтверждает их применение к рабочей базе.** Проверки RLS и Storage нужно выполнить отдельно в активном Supabase-проекте и с двумя тестовыми аккаунтами.

Экспорт JSON переносит отдельного персонажа и его портрет, если он доступен. Он **не заменяет** полную резервную копию базы данных, содержимого Supabase Storage и истории опубликованных шаблонов. Перед изменениями БД необходимо создать и проверить восстановимый бэкап. Не удаляйте старые шаблоны или миграции ради уменьшения истории.

Стабилизационный цикл Pathfinder HTML 8/8 завершён и прошёл автоматические проверки. Реальные устройства, одновременные редакторы и некоторые переносы сложного содержимого в PDF остаются предметом дополнительной приёмки.
