# Roboto Condensed for alternative PF2e abilities

Upstream: https://github.com/google/fonts/tree/main/ofl/robotocondensed
File: RobotoCondensed[wght].ttf, retrieved 2026-10-15 (unaltered variable font).
License: SIL Open Font License 1.1; the upstream copyright and full terms are in OFL.txt.

Compared Oswald Bold and Roboto Condensed Bold at the same size with all six Russian ability names. Roboto Condensed has less vertically stretched shapes and is closer to the supplied narrow sans-serif reference. Both support Cyrillic; Roboto Condensed was selected. Only alternative PF2e page-one ability names and partial-boost captions use this font. The original font file is bundled locally by Vite; no external font requests are needed.
